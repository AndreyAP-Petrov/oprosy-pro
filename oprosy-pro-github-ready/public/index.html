Добавить колонку

Ручной ввод или вычисляемая колонка с собственной формулой

Колонки указываются в квадратных скобках: [ПОКАЗЫ], [КЛИКИ], [АНКЕТЫ]. Можно ссылаться и на свои ручные колонки: например [ВЫРУЧКА].

fx Формулы — справочник

Готовые шаблоны + свой конструктор формул для дополнительных колонок

Как добавить формулу

  1. Нажмите «+ Добавить колонку».
  2. Выберите тип «Формула — считается автоматически».
  3. Выберите готовый шаблон или напишите формулу вручную.
  4. Формула пересчитывается сразу при изменении исходных ячеек и сохраняется вместе с настройками таблицы.

Готовые формулы

Примеры своих формул

SAFE_DIV([КЛИКИ],[ПОКАЗЫ])*100 — CTR.

IF([АНКЕТЫ]>=100,1,0) — отметка 1, когда собрано 100+ анкет.

SAFE_DIV([ВЫРУЧКА]-[ПОТРАЧЕНО С НДС],[ПОТРАЧЕНО С НДС])*100 — ROI после добавления ручной колонки «Выручка».

SAFE_DIV([ПРОДАЖИ],[АНКЕТЫ])*100 — конверсия в продажу после добавления ручной колонки «Продажи».
