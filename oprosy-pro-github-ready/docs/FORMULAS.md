# Формулы и вычисляемые колонки

## Стандартные ссылки

```text
[ПОКАЗЫ]
[КЛИКИ]
[АНКЕТЫ]
[ПОТРАЧЕНО БЕЗ НДС]
[ПОТРАЧЕНО С НДС]
[СТОИМОСТЬ КЛИКА С НДС]
[СТОИМОСТЬ АНКЕТЫ С НДС]
[ОСТАЛОСЬ]
[НУЖНО]
[ПРОЦЕНТ]
[БЮДЖЕТ С НДС]
[КОЭФФИЦИЕНТ]
```

На пользовательскую колонку можно ссылаться по её названию, например `[ВЫРУЧКА]` или `[ПРОДАЖИ]`.

## Функции

```text
SAFE_DIV(a,b)       безопасное деление, при нулевом b возвращает 0
PERCENT(a,b)        доля a от b в процентах
IF(cond,a,b)        условие
ROUND(x,n)          округление
MIN(...), MAX(...)
ABS(x)
CEIL(x), FLOOR(x)
SQRT(x)
POWER(a,b)
CLAMP(x,min,max)
```

## Примеры

### CTR

```text
SAFE_DIV([КЛИКИ],[ПОКАЗЫ])*100
```

### Конверсия из клика в анкету

```text
SAFE_DIV([АНКЕТЫ],[КЛИКИ])*100
```

### Цена анкеты с НДС

```text
SAFE_DIV([ПОТРАЧЕНО С НДС],[АНКЕТЫ])
```

### CPM с НДС

```text
SAFE_DIV([ПОТРАЧЕНО С НДС],[ПОКАЗЫ])*1000
```

### ROI

Сначала создайте ручную колонку `Выручка`.

```text
SAFE_DIV([ВЫРУЧКА]-[ПОТРАЧЕНО С НДС],[ПОТРАЧЕНО С НДС])*100
```

## Итоги колонок

Для пользовательской колонки можно выбрать:

- сумму;
- среднее;
- минимум;
- максимум;
- количество заполненных значений;
- отсутствие итогового расчёта.
