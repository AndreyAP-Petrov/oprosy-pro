Опросы PRO v2.7 — USER IDs + ALL OWNER + REGISTERED ONLY

1. Каждый пользователь получает постоянный ID вида:
   usr_xxxxxxxxxxxx

   ID создаётся один раз и хранится в серверной базе.
   Старым пользователям ID добавляется автоматически при первом запуске v2.7.

2. Все пользователи имеют роль OWNER.
   Новые пользователи сразу создаются OWNER.
   Старые user/admin автоматически мигрируют в OWNER.

3. Главный системный владелец Andrey.27101993@gmail.com защищён от удаления.
   Остальных участников команды можно удалять несмотря на роль OWNER.

4. Пароли остаются личными:
   - администратор/OWNER не видит пароль;
   - пользователь задаёт пароль сам по одноразовому коду;
   - у каждого своя 2FA.

5. Данные/таблицы защищены серверной сессией.
   /api/app не отдаёт статистики без действующей сессии активированного пользователя.
   Незарегистрированный посетитель видит только экран входа/активации, но не данные.

6. "Публичная статистика" означает публичную только внутри зарегистрированной команды.
   В интернет без авторизации статистика не отдаётся.

7. В управлении пользователями теперь видны:
   имя, email, постоянный ID, OWNER, статус активации и 2FA.
