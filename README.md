# Опросы PRO

Закрытый многопользовательский сервис для ведения статистики рекламных опросов, расчёта квот, построения общей сводки и создания пользовательских формул.

## Текущая версия

`2.7.0`

## Основные возможности

- закрытая авторизация без самостоятельной регистрации;
- постоянный уникальный ID каждого пользователя;
- индивидуальные пароль и TOTP-2FA;
- права OWNER для участников закрытой команды;
- публичные внутри команды и приватные статистики;
- ручной ввод показов, кликов, анкет, расхода без НДС и планового количества анкет;
- мгновенный пересчёт формул и автосохранение;
- коэффициент НДС, по умолчанию `1,22`;
- стандартные коллекторы и возрастные/региональные квоты;
- общая статистика с объединением парных коллекторов;
- пользовательские строки и колонки;
- ручные и вычисляемые колонки;
- библиотека формул, итоговые и средние значения;
- импорт, экспорт и расчёт квот;
- запуск в УЛЬЕ или на отдельном VPS.

## Быстрый запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

По умолчанию приложение откроется на:

```text
http://localhost:3000
```

Проверка состояния:

```text
GET /api/health
```

## Переменные окружения

Скопируйте `.env.example` как ориентир и задайте переменные средствами хостинга, PM2, Docker или УЛЬЯ. Сам проект не загружает `.env` автоматически.

Критически важные переменные:

- `PORT` — назначенный порт;
- `OPROSY_DATA_DIR` — постоянная папка данных;
- `DATA_ENCRYPTION_KEY` — ключ шифрования TOTP-секретов;
- `OPROSY_OWNER_ACTIVATION_CODE` — одноразовый код первой активации;
- `OPROSY_OWNER_EMAIL` — email главного владельца.

## Безопасность репозитория

В Git запрещено добавлять:

- `data/db.json`;
- `data/.master-key`;
- `OWNER_FIRST_LOGIN.txt`;
- реальные `.env`;
- пароли, токены, TOTP-секреты;
- резервные копии и пользовательские выгрузки.

Они исключены через `.gitignore`.

## Статус проекта

Проект находится в активной разработке. Текущее файловое серверное хранилище подходит для небольшой закрытой команды. Перед масштабированием рекомендуется переход на PostgreSQL и отдельный журнал аудита.
