# История изменений

## 2.7.0

- постоянные уникальные ID пользователей;
- все участники закрытой команды переведены в OWNER;
- серверная проверка доступа только для зарегистрированных и активированных пользователей;
- отображение ID, статуса активации и 2FA;
- сохранены приватные и публичные внутри команды статистики.

## 2.6.0

- пользовательские ручные и формульные колонки;
- библиотека формул;
- строка итогов и средних значений;
- объединение названия опроса в общей статистике.

## 2.5.0

- live-пересчёт формул;
- автосохранение;
- стандартный набор коллекторов;
- отключение устаревшего кэша интерфейса.
